# APP窗口容器 2032x960 最终修正版

用于 6480×960 超长车机屏幕的 APP 窗口容器。

## 本版功能
- 单区域基准 2032×960
- 默认顶部空白 80 px
- 默认底部空白 120 px
- 设置中显示当前真实 Display 分辨率和系统 Density DPI
- APP 卡片显示图标和名称，不显示包名
- APP 长按：关闭 APP / 删除快捷方式
- 自己创建窗口预设，不自动创建“区域默认”
- 预设支持名称、X、Y、宽、高、DPI
- 预设卡片尺寸较小，适合超长屏
- 启动 APP 时对系统顶部可见区域进行坐标偏移补偿
- GitHub Actions 已加入旧版 `com.example.carappjump` 源码清理步骤，避免 `R does not exist` 编译错误

## GitHub 打包
Actions → 构建 APP窗口容器 2032x960 DPI版 → Run workflow。
APK 位于 Artifacts 中。


## 本次版本调整

- 容器 APP 本身不再使用固定 2032×960 作为显示尺寸，直接以车机实际 Display 尺寸为准。
- 容器顶部固定留白 80 px、底部固定留白 120 px，用于让本容器自己的按钮区域向中间收缩，避开车机原车状态栏/底部按钮。
- 删除“设置”按钮和容器设置页面，不再提供上下留白的可编辑选项。
- 主界面右上显示车机实际显示分辨率。
- 新建预设默认使用车机真实分辨率，并自动避开容器上下留白区域。
- APP 预设仍可独立设置 X、Y、宽、高和 DPI。
- 长按 APP 的“关闭 APP”不再显示“关闭失败”；普通 Android 应用无法获得强制停止其它前台 APP 的系统权限，因此这里只发送后台关闭请求。
- 删除预设时不再强制保留一个默认预设。


## 第2版 UI 调整
- 移除主界面“APP 窗口容器”标题，顶部空间给窗口预设。
- 窗口预设区域加高。
- 新建预设所有输入项左侧显示字段名称。
- 预设名称支持中文。
- APP 单击选择，双击直接启动（不套用窗口预设）。
- 添加 APP 按钮移动到已添加 APP 列表下方。

## 第3版 UI 调整
- 使用新的窗口/APP 容器图标作为 APK 图标
- 删除车机实际显示信息
- 容器顶部固定留白 80 px、底部固定留白 120 px
- 窗口预设直接从顶部 80 px 留白之后开始显示
- “窗口预设”右侧使用 + 按钮新建预设
- “已添加 APP”右侧使用 + 按钮添加 APP
- 删除底部的大型添加按钮
- 预设卡片固定三行：名称 / 位置与分辨率 / DPI
