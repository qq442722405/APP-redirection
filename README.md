# APP窗口容器 - 手动间距调整最终版

本版基于上传的“APP窗口容器_触控修复_间距快速调整版”修复。

## 本版确定功能

- 删除所有触控纠正、触控 X/Y 偏移补偿代码。
- 新建/编辑窗口预设改为主 Activity 内嵌编辑界面，不使用独立 Dialog Window。
- 预设支持中文名称。
- 字段名称固定显示在输入框左侧：
  - 预设名称
  - 左边间距
  - 上边间距
  - 窗口宽度
  - 窗口高度
- 左边间距、上边间距、窗口宽度、窗口高度均提供：
  `+100`、`-100`、`+10`、`-10`、`重置0`
- 删除 DPI 设置。
- 删除全屏测试按钮。
- 添加 APP 支持“全部APP / 系统APP / 用户APP”分类。
- APP 以方形图标和名称显示。
- 双击已添加 APP 可直接启动，不使用窗口预设。
- 选择 APP 后点击窗口预设，可通过 Android `ActivityOptions.setLaunchBounds()` 请求指定位置和大小。
- 多个 APP 可以分别使用不同预设启动。
- 对强制全屏 APP 不宣称强制窗口；目标 APP 或车机 WindowManager 可以忽略 LaunchBounds。

## 重要说明

车机真实 Display 如果是 6480×960，可以手动设置：

- 左区：X=0
- 中区：X=2160
- 右区：X=4320

Y、宽度、高度直接按车机实际像素填写。

本 APK 不再对触控事件进行任何人为坐标修正。
