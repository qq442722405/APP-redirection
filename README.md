# APP窗口容器｜自动启动编译修复版

本版本基于上一版工程修复：
- 修复 APP 自动启动编辑器 `Runnable render` 自引用导致的 Java 编译错误。
- 新建/编辑窗口预设点击“完成”才保存。
- 主界面“启动：开/关”控制进入容器后是否执行自动启动任务。
- 自动启动设置采用“添加 / 保存 / 关闭”，保存前只修改草稿。
- 多个自动启动任务按 1 秒间隔依次启动。
- 预设为空时只启动 APP，不套用窗口位置和大小。
- 窗口模式 1~5 保留并记忆默认模式。

GitHub Actions：手动运行 `workflow_dispatch`，生成 Debug APK。
