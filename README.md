# APP窗口启动器（第79版）

本版本基于第78版继续整理，目标是保持现有功能并提高 GitHub Actions 构建失败时的可诊断性。

主要保留/修正：
- 所有应用弹窗统一不透明，并统一从顶部 80dp 以下显示，避免车机触控坐标偏移。
- 设置中的“开机启动”位于第一排；“开机延迟启动、主界面字体大小、主界面界面大小、弹窗左边距、弹窗右边距”统一放入“界面选项”，手动输入后保存。
- 添加 APP 支持“全部 / 用户 / 系统”分类，应用图标+名称网格显示，列表可上下滚动。
- 新建窗口预设支持“复制 / 粘贴 / 取消 / 保存”。
- 保留自动启动多个任务和任务间隔。
- 删除旧 shortcuts.xml 和旧包名残留。
- GitHub Actions 构建失败时自动输出最后 250 行构建日志，避免只看到 Gradle 堆栈看不到真正的第一条错误。
