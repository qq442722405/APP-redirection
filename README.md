# APP窗口容器 2032×960 DPI版

## 本版本核心

车机每个区域固定：

**2032 × 960**

不再把整个 6480×960 当作一个区域。

容器 APP 本身按照一个 2032×960 区域设计。

## 界面

- 黑色背景
- 白色文字
- 右上角设置
- APP 以小方格显示
- 小方格显示 APP 图标 + APP 名称
- 不显示包名

## 设置

右上角“设置”中：

1. 容器 DPI
2. 容器顶部空白
3. 容器底部空白

这些设置针对的是**这个 APP 窗口容器本身**。

不是被添加 APP 的窗口限制。

## APP预设

预设可以保存：

- 名称
- X
- Y
- 宽度
- 高度
- APP DPI

使用：

先点 APP → 再点窗口预设。

## 默认尺寸

新建预设默认：

2032 × 960

如果需要一个区域铺满，可以设置：

X=0
Y=0
宽度=2032
高度=960

## 三个区域

在 6480×960 车机上：

第一区域：
X=0 ~ 2032

第二区域：
X=2032 ~ 4064

第三区域：
X=4064 ~ 6096

如果你的车机三个实际区域正好如此，可以分别创建：

左区：
X=0

中区：
X=2032

右区：
X=4064

宽度：
2032

高度：
960

## DPI说明

当前工程已经把 DPI 纳入容器设置和 APP 预设。

普通 Android Activity 的 DPI 并不能保证通过 ActivityOptions 直接修改第三方 APP 的真实 Display Density。

所以本版本不会伪装成已经修改了系统 DPI。

如果车机系统支持对应的窗口/Display API，后续可以继续接入。


## 触控修正版

- 默认顶部空白 80 px
- 默认底部空白 120 px
- 删除自动生成的“区域默认”预设，预设由用户自己添加
- 设置 → 容器设置显示当前区域真实分辨率和当前系统 Density DPI
- 保存的预设按钮缩小，便于超长屏显示
- APP 卡片显示图标 + 名称
- APP 长按提供“关闭 APP”和“删除快捷方式”
- 启动窗口 Bounds 增加系统顶部可见区域偏移补偿，针对车机状态栏导致的上下偏移进行修正
