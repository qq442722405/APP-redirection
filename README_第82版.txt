APP窗口启动器 第82版

本版修复重点：
1. 主界面字体大小、主界面界面大小输入范围统一为 50-300%。
2. 已添加 APP 主界面固定三列排列，超过可视区域后通过外层 ScrollView 上下滚动。
3. 设置中的开机延迟、主界面字体大小、主界面界面大小、弹窗左右边距统一放入“界面选项”，点击后弹出独立界面，并使用“保存设置”统一保存。
4. 保留上一版的触控偏移修复、弹窗左右边距、APP分类、预设复制粘贴等功能。
5. 本版 MainActivity 保持方法和类的完整闭合，避免出现方法嵌套导致的 '; expected' / 'illegal start of expression' 连锁编译错误。
