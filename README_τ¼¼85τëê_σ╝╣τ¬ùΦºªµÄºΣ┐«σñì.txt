APP窗口启动器 第85版

本版重点修复：
1. 取消所有普通弹窗 Window 的 TOP/LEFT + x/y 定位方式，统一改为 CENTER。
2. 不再使用 lp.y=80 等人为坐标偏移，避免车机状态栏/安全区造成视觉位置与触控位置不一致。
3. 所有通过 showDialogBelowTop() 打开的 AlertDialog 统一使用该定位方案。
4. 弹窗默认宽度限制为屏幕约 70%，并限制最大 1200dp，避免超宽屏弹窗过大导致按钮看不到。
5. 保留设置中的“弹窗左边距/弹窗右边距”作为可用宽度计算参数。
6. 弹窗保持不透明。

说明：本环境没有安装 Gradle/Gradle Wrapper，因此这里只完成工程修改并打包工程文件，未在本环境执行 assembleDebug。请直接上传到 GitHub Actions 构建测试。
